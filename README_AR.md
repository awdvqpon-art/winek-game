# وينك؟! V3 — ماب البيت أونلاين

نسخة V3 مجهزة للنشر على استضافة Node.js مثل Render.

## المزايا
- 16:9 ومتجاوب مع الهاتف.
- غرف أونلاين بكود.
- حتى 8 لاعبين.
- باحث + مختبئون.
- 4 غرف: الصالة، النوم، المطبخ، الحديقة.
- 4 أماكن اختباء: كنبة، سرير، خزانة، شجرة.
- الباحث يمسك أقرب مختبئ غير مختبئ ضمن مسافة محددة.
- 180 ثانية.
- فوز الباحث إذا أمسك الجميع.
- فوز المختبئين إذا انتهى الوقت.
- `/health` لفحص السيرفر.

## تشغيل محلي
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

## نشر Render
ارفع المشروع إلى GitHub، ثم في Render اختر New > Web Service، اربط المستودع.
Build Command: `npm install`
Start Command: `npm start`

Render سيعطيك رابط HTTPS. افتح الرابط من الهاتف وشارك الرابط مع أصدقائك.

ملاحظة: هذه نسخة لعب فعلية أونلاين كبنية أساسية، وليست لعبة تجارية نهائية. الرسومات حالياً واجهة/رموز، ويمكن لاحقاً استبدالها بشخصيات وموديلات وصوت ومؤثرات.
